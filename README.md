# Inky Fox Brief

Интерактивный первичный бриф на разработку MiniApp / веб-страницы.

## Что внутри

- квиз вместо длинной формы;
- имя и Telegram пользователя;
- вопросы по проекту, цели, воронке, текстам, дизайну, интеграциям и срокам;
- сохранение ответов в `localStorage`;
- адаптив под мобильный MiniApp и десктоп;
- финальная сводка с копированием, системным «Поделиться» и скачиванием `.txt`;
- фирменный тёмный стиль Inky Fox.

## Запуск

Проект статический. Достаточно открыть `index.html` или опубликовать репозиторий через GitHub Pages / любой статический хостинг.

## Файлы

- `index.html` — каркас приложения;
- `styles.css` — визуальная система и адаптив;
- `app.js` — логика квиза, валидация, сохранение и формирование брифа;
- `asset-loader.js` — загрузка фирменного маскота;
- `assets/inky-fox.b64` — маскот в текстовом base64-представлении для статического хостинга.
